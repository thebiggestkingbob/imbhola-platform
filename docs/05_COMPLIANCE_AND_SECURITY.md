# 05 — Regulatory safety and security

## SETA gate
No SETA selected. Official export disabled by default, irrespective of the user interface. Each adapter/version must store authority, source URL/file hash, applicable reporting year, test fixtures, reviewed-by and approved-by, effective dates, and rollback procedures. Enforce verification on server for any official export.

## Financial statements
Separate estimated potential, eligible subject to review, applied, approved, paid and reconciled states. Never promise grants or describe estimates as money received. Historic illustrations are not current calculations.

## POPIA-conscious architecture
Define controller/operator responsibilities and processing agreements; collect minimal personal data; isolate tenants; encrypt data in transit/at rest; protect national IDs and sensitive demographics; audit administrative access; implement retention and data subject rights as legally reviewed. No live employee data until documented legal/security gates are passed.

## Operational checks
MFA for privileged roles, malicious-file scanning, least-privilege object storage, expiring file links, restore-tested backups, incident procedures and monitoring. External AI access to personal data disabled unless formally authorized. Prefer private repository when original client documents or proprietary specifications are added.
