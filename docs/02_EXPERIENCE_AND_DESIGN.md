# 02 — Design direction and user experience

**Locked direction:** 04, Editorial Enterprise. Elegant editorial hierarchy; substantial whitespace; readable typography; clean structured dashboards; warm ivory, forest/ink and restrained clay as **provisional** tokens, not final brand approval.

## Site experience
Clear user paths from awareness to solution comparison, about/trust, contact/demo, signup, verification and appropriate workspace. Avoid dead-end buttons and misleading functional appearance.

## Role workspace
Each role sees only its tasks and authorized records. SDF can switch authorized client organizations; employees see only their own learner/training records. Executives see progress and confirmed financial states; signatories see approval packs and audit history. Include loading/empty/errors on every data view.

## Accessibility
Semantic headings, visible focus, keyboard navigation, touch targets, reduced motion, readable text contrast and mobile validation. Test against WCAG 2.2 AA targets; don't claim certification without independent validation.

## Reference handling
Approved visual image is an art-direction reference, not a source of facts, marketing copy, or finished production UI. Do not improvise official reporting terminology based on illustrative mock text.
